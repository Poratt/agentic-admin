אם תוסיפו את היכולת הזו, הדיאלוג הזה של **Edit Model** יהפוך מטופס טכני יבש ללוח בקרה סופר-עשיר, וזה ישדרג את כל התנהגות הסוכן שלכם.

הנה איך כדאי לממש את זה בצורה אלגנטית ומדויקת בסטאק שלכם:

---

### 1. איך זה ייראה ב-UI (Angular 22)?

1. **כפתור קסם ליד ה-Key:**
   - ליד שדה ה-`Key` מוסיפים כפתור קטן: **`✨ Auto-Detect`** (או זיהוי אוטומטי ב-`blur` ברגע שמסיימים להקליד).
2. **שדות מטא-דאטה שמתמלאים אוטומטית (עם אפשרות עריכה ידנית):**
   - **Context Window (Ctx):** למשל `128,000` (או תגית יפה כמו `128K`).
   - **Max Output:** למשל `4,096` טוקנים.
   - **Pricing (עלות ל-1M טוקנים):**
     - Prompt: `$0.15`
     - Completion: `$0.60`
     - או צ'קבוקס ירוק: `Is Free Tier` (כמו שראינו ב-OpenRouter/xKiro).

---

### 2. מאיפה הבקאנד (NestJS) מביא את הנתונים האלה?

בפרוטוקול OpenAI הרגיל, קריאת `GET /v1/models` מחזירה לרוב רק `{ id, created }` בלי נתוני מחיר וקונטקסט. לכן, הפתרון הנכון ב-Backend הוא **Cascade (שכבות חיפוש):**

#### מקור א': פנייה ל-API של OpenRouter (המאגר הכי עשיר ברשת)

ל-OpenRouter יש endpoint חינמי לחלוטין שמחזיר JSON עם **כל המפרט** של כל מודל קיים בעולם:
`GET https://openrouter.ai/api/v1/models`
התשובה כוללת:

```json
{
  "id": "meta-llama/llama-3.1-8b-instruct",
  "context_length": 131072,
  "pricing": {
    "prompt": "0.000000055",
    "completion": "0.000000055"
  },
  "top_provider": {
    "max_completion_tokens": 8192
  }
}
```

ה-NestJS פשוט שולף מהקטלוג שלהם לפי התאמת שם/מפתח!

#### מקור ב': שימוש ב-Catalog הפתוח של LiteLLM (Static / Cached)

לקהילת הקוד הפתוח יש קובץ JSON שמתעדכן מדי יום:  
`model_prices_and_context_window.json`  
אפשר לשמור עותק מקומי שלו ב-NestJS (או למשוך אותו פעם ביום לקאש), והוא מחזיק את ה-Context והמחירים של אלפי מודלים (כולל Qwen, DeepSeek, Mistral וכו').

#### מקור ג': ה-WebSearchModule שכבר בניתם! (למודלים נישתיים)

אם מדובר במודל פנימי או משהו שלא מופיע ברשימות (כמו `agnes-2.0-flash`), ה-Backend יכול להריץ שאילתה מהירה דרך ה-`WebSearchModule` שלכם: `"agnes-2.0-flash context window pricing"` ולחלץ את זה אוטומטית.

---

### 3. למה זה שווה זהב לסוכן שלכם? (הערך האמיתי)

זה לא רק "נתונים יפים בטופס" – הנתונים האלה יקפיצו את היכולות של המערכת:

1. **מניעת שגיאות Context Limit:**
   הסוכן יידע בדיוק מתי לחתוך את היסטוריית השיחה (Truncate) כדי לא לעבור את ה-Ctx של המודל הנבחר.
2. **חישוב עלות שיחה בזמן אמת:**
   במסך הסטטיסטיקות שלכם, ליד ה-Latency וה-Success Rate, תוכלו להוסיף עמודת **`Total Cost ($)`** ולדעת בדיוק כמה כסף חסכתם או בזבזתם על כל ספק ומודל.
3. **Smart Fallback מבוסס גודל פרומפט (למשימה הגדולה הבאה!):**
   אם משתמש שולח קובץ ענק של 50,000 טוקנים, והמודל הראשי נפל – ה-Router לא ינסה אפילו לעשות Fallback למודל עם 16k context, אלא יסנן אך ורק מודלים שתומכים ב-Ctx הדרוש.

---

- **DB:** הוספת עמודות `context_length`, `prompt_price`, `completion_price` ב-`LlmModelEntity`.
- **Backend:** מתודת `enrichModelMetadata(key: string)` שמחפשת בקטלוג OpenRouter/LiteLLM.
- **Frontend:** הוספת שדות ה-Ctx והמחיר בדיאלוג שבתמונה עם כפתור `Detect`.
